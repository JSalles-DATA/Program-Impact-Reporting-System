# Program Impact Reporting System

## Overview
This project simulates how a community organization can use data to measure
the impact of its programs.

It demonstrates a complete **data pipeline**:
1. Data generation
2. Data cleaning
3. Data analysis and reporting

The project is intentionally simple, beginner-friendly, and fully runnable
on **Termux (Android)** without internet access.

---

## What This Project Does
- Generates realistic program participation data
- Cleans and validates the data safely
- Calculates key performance indicators (KPIs)
- Produces visual reports (PNG charts)
- Prints clear summaries for decision-makers
